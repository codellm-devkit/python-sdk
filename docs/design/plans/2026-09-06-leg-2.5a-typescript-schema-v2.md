## Task 1: TypeScript v2 models

> Refined from the schema inventory (`schema.ts` at `v1.2.0`, `emit.ts`'s `stripInternal`, `ids.ts`, `attach.ts`). Decisions TS-5 … TS-10 below are recorded in `.claude/FACADE_DECISIONS.md`.

**What the wire actually carries (authority: `v1.2.0:src/schema/schema.ts`, stripped by `emit.ts:47-70`):**

- Envelope `TSAnalysis{schema_version:"2.0.0", language:"typescript", max_level, k_limit?, analyzer{name,version}, application}`. `k_limit` only at L3+.
- `TSApplication{id, kind:"application", symbol_table, call_graph, param_in, param_out, artifacts, dependencies, unresolved_imports, config_uses, config_reads, external_symbols?, synthesized_callables?}` — `config_reads` (not Python's `config_reads_unresolved`); `external_symbols` is keyed by the entry's own `id` (`TSExternalNode`); **`synthesized_callables` is a compatibility index: its keys are the *older* anonymous-callable ids (`…/Controller@5:10`) and each value's `id` is the tree id that replaced it (`…/Controller/<anon@5:10>`) — key ≠ `id` in every fixture** (`TSSynthesizedNode`; residual fallback nodes are the only key == id case). An index over it must say which id it keys. `main` adds `entrypoint_report` (required there).
- `TSModule{id, kind:"module", span, source, imports, exports, comments, types, functions, fields, is_tsx, is_declaration_file, content_hash?}` — **no `file_path`/`module_name`** (the map key is the file key); `last_modified`/`file_size` are stripped.
- `TSType{id, kind ∈ class|interface|enum|type_alias|namespace, span, name, signature, comments, is_exported, is_ambient, + optional facets}`: `callables` (class/interface), `fields` (class/interface/**enum members**/namespace), `types`+`functions` (namespace), `decorators`, `base_classes` (extends ∪ implements, signatures), `implements_types`, `is_abstract`, `type_parameters`, `call_signatures`, `index_signatures`, `is_const`, `aliased_type`, `extends_ids`, `implements_ids`.
- `TSCallable{id, kind ∈ function|method|constructor|getter|setter|arrow|function_expression, span, name, signature, comments, decorators, parameters, type_parameters, overload_signatures, return_type?, accessibility?, accessor_kind?, cyclomatic_complexity, is_static, is_abstract, is_async, is_generator, is_optional, is_readonly, is_exported, is_ambient, is_implicit, body, callables?, types?, cfg?, cdg?, ddg?, summary?}` — **declared but never emitted: `abs_path`, `call_sites`, `config_accesses`** — do not model them; **no `code`, no `path`, no `accessed_symbols`, no `local_variables`, no `code_start_line`**.
- `TSCallableParameter{name, type?, default_value?, accessibility?, is_optional, is_rest, is_readonly, decorators, start_line, end_line, start_column, end_column}` (flat ints, not a span). `main` adds `id?`.
- `TSField{id, kind:"field", name, span?, type?, initializer?, scope?, declaration_kind?, is_exported?, comments?, decorators?, accessibility?, is_static?, is_readonly?, is_optional?, is_abstract?, value?}` — one open shape for module variables, class attributes, interface properties and enum members. `span` is absent for constructor parameter properties.
- `TSBodyNode{kind: str, span?, callee?: str|None, of?, parent?, method_name?, receiver_expr?, receiver_type?, argument_types?, type_arguments?, return_type?, is_constructor_call?, is_optional_chain?, root?, key?}`. Observed kinds at L4: `entry exit statement call config_access formal_in formal_out actual_in actual_out`. `callee` is the one sanctioned `null` (L1). `main` adds `id?`.
- Edges: `TSCfgEdge{src,dst,kind}` (kinds `fallthrough true false switch_case loop_back exception return break continue yield await_resume`), `TSCdgEdge{src,dst}`, `TSDdgEdge{src,dst,var?,prov: List[str]}` (1.2.0 emits only `["reaching-defs"]`; the analyzer's own comment reserves `ssa`/`points-to` — **not a `Literal`**), `TSSummaryEdge{src,dst,var?}`, `TSCallGraphEdge{src,dst,prov: List[str],weight}` (prov `tsc`/`defuse`/`import`, open), `TSParamEdge{src,dst,var?}` with **global** endpoints. Intra-callable edge endpoints are bare local keys.
- Artifacts: `TSArtifact{id, kind:"artifact", path, format, roles, size_bytes, sha256, source, extraction, config_keys}`, `TSDependency{name, spec, kind ∈ runtime|dev|optional|peer|build, extras, declared_in, direct, locked_version?, provides_imports, prov}` (no `ecosystem` — Python has it), `TSConfigKey{id, key, namespace, value?: str|int|float|bool, span?, references}`, `TSImportBinding{module, bound_to?, prov}`, `TSConfigUse{src,dst,prov}`, `TSConfigRead{site, callee, key?, reason, prov}`.
- Ids: application `can://typescript/<app>` (always `typescript`); module `can://<typescript|javascript>/<app>/<fileKey>` (`.js/.jsx/.mjs/.cjs` → `javascript`); type/callable = module id + `/` + the signature segments after the module prefix; field `<parentId>/<name>`; external `<appId>/@external/<module>/<name>`; synthesized `<enclosing>@<line>:<col>` or `<appId>/@synthetic/<encoded sig>`; artifact `can://artifact/<app>/<rel>`; config key `<artifactId>@key/<dotted>`; package `pkg:npm/<name>`.
- Body keys: `L:C`; L1 collisions `L:C/2`, `L:C/3`; **L3 collisions `L:C#<nodeId>`** (a different scheme); `@entry`, `@exit`, `@formal_in:N`, `@formal_out`, `L:C/actual_in:N`, `L:C/actual_out`. Global ordinal = `callableId + key` if the key starts with `@`, else `callableId + "@" + key` — identical to codeanalyzer-python's `global_ordinal`. Any key parser must not `split("/")` naively: `L:C/2` collides with the `L:C/actual_out` family.

**Decisions taken here (recorded as TS-5 … TS-10):**

- **TS-5 `types{}` is a discriminated union** `Annotated[Union[TSClass, TSInterface, TSEnum, TSTypeAlias, TSNamespace], Field(discriminator="kind")]`. G3 forces it: the five classes are the return types of existing accessors. `TSModule.classes/interfaces/enums/type_aliases/namespaces` become read-only `@property` filters over `types` so every 1.x attribute path keeps working. An unknown sixth kind fails validation loudly — the same drift alarm as `extra="forbid"`.
- **TS-6 `TSSpan` is modelled faithfully**; every model that used to expose `start_line`/`end_line` keeps them as computed properties over `span` (G3 for attribute access). Leaf models that the analyzer still emits with flat ints (`TSImport`, `TSComment`, `TSDecorator`, `TSCallableParameter`) stay flat.
- **TS-7 `code` is synthesised, not stored:** a `code` property slices `module.source[span.bytes[0]:span.bytes[1]]` as **characters** — `schema.ts:29-31` declares `bytes` as UTF-16 offsets. The Neo4j projection slices bytes (`project.ts:274-280`) and disagrees on non-ASCII files; filed upstream, and stated as documented lossiness between the two backends until it is fixed. The `TSCallableOverview` projection threads the owning module in so `code`/`start_line` keep their values.
- **TS-8 `extra="forbid"` stays, and 1.3.0's known additive fields are `Optional` now:** `TSBodyNode.id`, `TSCallableParameter.id`, `TSCallable.entrypoints`/`is_entrypoint`, `TSType.entrypoints`/`is_entrypoint`, `TSApplication.entrypoint_report` (required on `main`; `Optional` here parses both generations), `TSModule.call_sites` (internal on `main`, stripped — not modelled). The pin bump to 1.3.0 is then a deliberate step that changes no model, and any *other* drift still fails loudly.
- **TS-9 the call-edge class is `TSCallGraphEdge{src, dst, prov, weight}`**, with `TSCallEdge = TSCallGraphEdge` kept as an import alias. The field change is BREAKING-by-value in the CHANGELOG, as `PyCallEdge`'s was in leg 1. `TSExternalSymbol`/`TSSynthesizedCallable` are retyped to the wire's id-keyed `TSExternalNode{id, kind, module, name}` / `TSSynthesizedNode{id, kind, name?, path?, span?}`.
- **TS-10 the in-memory call graph stays signature-keyed** (as Python's `_id_to_signature` does), with the `can://` id as a node attribute — cross-language parity and G3. The index joins edges to nodes by id and maps to signatures once at load; `external_symbols` is indexed by id.
- **TS-11 TypeScript's call graph keeps its own endpoints.** cants emits modules as callers (top-level code) and classes as callees (`new X()`), e.g. `src/controllers.ts → controllers.ts/Controller`. Python's leg-1.6 rule (drop non-callable sources and class targets) would erase every top-level call, so `get_call_graph()` on TypeScript keeps them, with a `kind` node attribute so a caller filters to Python's shape in one line. **As shipped the vocabulary is eight values, not the four written here when the plan was drafted:** `module | class | interface | enum | type_alias | namespace | callable | external` — every declaration kind the analyzer can put on a `TS_CALLS` endpoint, since `_graph_key` passes a type endpoint's own `kind` through rather than collapsing it to `class`. The divergence is stated in the spec's §4 and the agent reference, not normalised away. Applies to both backends identically (T2 local, T3 Neo4j).

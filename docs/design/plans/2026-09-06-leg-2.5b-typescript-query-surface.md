# Leg 2.5b — the TypeScript query surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give TypeScript the agent-facing query surface Python gained in legs 1.5 and 1.6 — addressing, per-callable graphs, bounded slices and flows, entrypoints, and the artifact/config layer — on both backends, on codeanalyzer-typescript 1.3.0, with every pre-existing accessor unmoved.

**Architecture:** Four moves. (T0) `LocateResult` goes language-neutral (TS-1) so `commons/results.py` stops importing `cldk.models.python`, and the pin moves to 1.3.0 — a change that must alter no model, since 2.5a pre-declared 1.3.0's additive fields. (T1) The addressing surface on both backends: `locate`, `locate_many`, `resolve_callable`, `resolve_value`, `get_source`, `describe`, `has_resolution_edges`, plus the scoping keywords on the existing accessors. (T2) The dataflow surface: per-callable `EdgePage`s, slices, reachability, paths, flow predicates — Python's bounds and completeness protocol, no new rulings. (T3) Entrypoints, the artifact/config layer on the facade, the multi-application audit over every new statement, docs.

**Tech Stack:** Python 3.11+, pydantic v2, neo4j driver 5.x, codeanalyzer-typescript 1.3.0 (bun-compiled binary in the PyPI wheel; `--emit neo4j` is always full depth).

**Spec:** `docs/design/specs/2026-09-06-leg-2.5-typescript.md` (TS-1, TS-2, TS-3, and the 2.5b half of TS-4). Tracking: python-sdk#343 under codellm-devkit/.github#55.

## Global Constraints

- **Nothing pre-existing moves.** `tests/analysis/typescript/test_typescript_public_surface.py` freezes 46 accessors' signatures; this leg's frozen list grows by exactly what it adds and changes no existing entry. Any other diff is a defect.
- **Python's semantics are the contract, not a starting point.** Every accessor this leg adds must match `cldk/analysis/python/python_analysis.py`'s signature and semantics exactly, including keyword-only-ness, defaults, and which bound is finite. The exact signatures to mirror are in each task. Where TypeScript genuinely cannot answer, it raises naming the gap — never an empty that reads as a fact (D7).
- **Bounds are never silent (E5).** Slices and cones default `depth` to `DEFAULT_DEPTH` and cap `max_nodes`; `reaches`, `paths_between`, `call_paths_between`, `flows_to_call` and `flows_to_argument` are **unbounded by default** (`depth=None`) because a bounded predicate returns a wrong answer, not a small one. One completeness protocol: the `complete` field on `EdgePage`/`Slice`/`FlowPaths`.
- **No `can://` and no ordinals** in any signature, in any return field other than `ref`/`node_id`/`next_cursor`, or in any error message (E6/E7). Errors name what missed; no suggestions, no fuzzy matching, anywhere, including error paths (E8).
- **Two prefixes (TS-3).** Application scope stays the list `can://typescript/<app>/` and `can://javascript/<app>/`, spelled through the existing `_scoped()` helper as `$p1 OR $p2` — never `any()`, which measurably defeats the index seek.
- **Seek labels are measured, not assumed.** 2.5a's measured rule: bare label for signature and prefix statements, `:CanNode:<Label>` only for id-equality point lookups. Re-measure for any new statement family (`PROFILE`, median of 5) and record the numbers in this file. Java's leg 3a found the opposite ruling on its own graph; do not port a rule across languages.
- **Read-only against every Neo4j instance.** Reference graph: `bolt://localhost:7692`, user `neo4j`, password `cldkleg25btest`, application `superset-frontend`, emitted by the **released 1.3.0 wheel** (154,451 nodes / 449,394 relationships; anchor stamps `analyzer_version 1.3.0`; `k_limit 3`). The 2.5a graph on 7690 stamps `1.2.0` and is kept as the below-floor refusal fixture. Python regression graph: `bolt://localhost:7689` / `cldkleg16test` / `odoo-slim-19`. **Port 7687 is an ssh tunnel; never a target.** Containers are in the `podman` docker context. The two TypeScript live-writer files stay gated on `CLDK_TEST_NEO4J_WRITE_*`; never set those.
- Run suites **sequentially**. Stage by name. Worktree `<scratchpad>/wt-leg25b` (branch `feat/issue-343-ts-query-surface`), stacked on 2.5a's head `0170f67`; rebase onto `release/2.0` once #342 merges.

- [ ] **Step 1: Failing tests, offline.** Per-callable pages: the first page of a callable's CFG is complete for a small callable and `complete is False` with a `next_cursor` for a large one; paging with the cursor yields the rest and never repeats an edge; `page_size=0` and a bad cursor raise naming the argument. Slices: a backward slice from a value inside a callable; the default depth is finite and a truncated slice reports `complete is False`; `max_nodes` caps and says so. Predicates: `reaches` is unbounded by default; a `depth` that cuts a known-true path returns `False` **and** that asymmetry is the reason predicates are unbounded — assert the unbounded call is `True`. Paths: `paths_between` with the two scopes; `max_paths` truncation reported. `flows_to_argument` with a real argument position.

# CLDK 2.0 Leg 1.5 — Bounded Queries and Dataflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the enumerating accessors bounded, give callers a way to name nodes without touching a `can://` URI, and expose the dataflow graph the projection already carries.

**Architecture:** Three layers, built in order. First, collapse the Neo4j N+1 fan-out so a symbol table costs a handful of queries instead of 73,669. Second, a resolver turning names a caller already knows (`"invoice_id"`, `"PaymentPortal.invoice_transaction"`) into internal node handles, with ambiguity raised rather than guessed. Third, slicing, reachability and path queries executed as variable-length Cypher in the database, returning readable descriptors rather than identifier strings.

**Tech Stack:** Python 3.11+, pydantic v2, neo4j driver, pytest, `codeanalyzer-python` 1.4.0, Neo4j 5.x.

**Spec:** `docs/design/specs/2026-09-05-leg-1.5-bounded-queries-and-dataflow.md`

**Tracking:** #321, epic codellm-devkit/.github#55. Builds on leg 1 (#322, 46 commits).

## Global Constraints

- **Public API signatures do not move.** Everything shipped in leg 1 is frozen. New capability arrives as new accessors; bounds arrive as **defaulted keyword arguments**, which are an accepted widening in this repo (precedent: `neo4j_username`/`neo4j_password` gaining `= None`, `get_dependencies` gaining filters).
- **Pre-existing assertions may not be edited.** Add tests freely; touch no existing `assert`. If one must change, STOP and report — that is an API break.
- **No `can://` URI appears in any public signature or return type** (spec E6). Internal handles ride on `SliceNode.ref`, documented as not-for-reading.
- **No ordinals in the public surface** (spec E7). No `formal_in:1`, no `actual_in:0`. `flows_to_argument` takes the callee's parameter *name*.
- **Ambiguity raises with candidates; nothing is auto-picked** (spec E8). Suffix matching on the dotted name is supported and deterministic. Typo-tolerant matching is **out of scope entirely** — not in the resolver, not in the error path.
- **Neo4j is read-only.** No `CREATE`, `MERGE`, `SET`, `DELETE` in any Cypher, including test setup.
- **Anything added to a shared ABC must be implemented on both** `PyNeo4jBackend` and `PyCodeanalyzer` in the same change, or the class stops instantiating. `tests/analysis/python/test_python_backend_contract.py::test_backend_fully_implements_contract` is the guard.
- **Every capped accessor reports `truncated`.** No cap is silent (spec E5).
- Python `>=3.11`, pydantic `>=2.10.6,<3`, `codeanalyzer-python==1.4.0`. No new dependencies.
- **Verify every label, property and model field against the installed analyzer before asserting on it.** Leg 1 shipped three bugs from asserting properties the emitter never writes — one in a fixture that passed a full review, one in production code.

- [ ] **Step 3: Write the resolution policy in `resolve.py`**

Pure functions over candidate lists — no Cypher, no driver. Given a query name and candidates, decide: exact match wins; otherwise dotted-suffix match on segment boundaries (`"execute"` matches `db.cursor.execute`, `"cursor.execute"` narrows); one survivor resolves; more than one raises `AmbiguousName` carrying them; none raises the existing not-found error. **No similarity scoring anywhere.** Keeping this file free of I/O is what lets it be tested without a graph.

  class PathHop(BaseModel):
      frm: SliceNode
      to: SliceNode
      via: str                  # data | control | argument | return | summary
      var: str | None

  class FlowPath(BaseModel):

  # callable); paths_between takes two callables, neither defaulted; depth is unbounded by default

  def call_paths_between(self, src: str, dst: str, *, depth: int | None = None, max_paths: int = 10) -> FlowPaths: ...
  def flows_to_call(self, src: str, callee: str, *, within: str, depth: int | None = None) -> bool: ...
  def flows_to_argument(self, src: str, callee: str, arg: str,
